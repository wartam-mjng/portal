Transformasi

Memahami empat jenis transformasi geometri: refleksi (pencerminan), translasi (pergeseran), rotasi (perputaran), dan dilatasi (perkalian).

Ringkasan Materi

1. Refleksi (Pencerminan)

Refleksi adalah perpindahan titik atau bangun dengan cara dicerminkan terhadap suatu garis (cermin). Sifatnya: jarak titik ke cermin sama dengan jarak bayangannya ke cermin, serta bentuk dan ukuran bangun tidak berubah (kongruen).

Titik P(x, y) direfleksikan menjadi:
• terhadap sumbu x → (x, −y)
• terhadap sumbu y → (−x, y)
• terhadap titik O(0, 0) → (−x, −y)
• terhadap garis y = x → (y, x)
• terhadap garis y = −x → (−y, −x)
• terhadap garis x = h → (2h − x, y)
• terhadap garis y = k → (x, 2k − y)
Contoh: Titik A(2, 3) dicerminkan terhadap sumbu x menjadi A′(2, −3).

2. Translasi (Pergeseran)

Translasi menggeser setiap titik sejauh (a, b): bergeser |a| satuan ke kanan (a positif) atau ke kiri (a negatif), dan |b| satuan ke atas (b positif) atau ke bawah (b negatif). Bentuk dan ukuran bangun tetap.

Titik P(x, y) oleh translasi T(a, b) menjadi P′(x + a, y + b)
Contoh: Titik B(1, −2) digeser oleh T(3, 4) menjadi B′(1 + 3, −2 + 4) = B′(4, 2).

3. Rotasi (Perputaran)

Rotasi memutar titik atau bangun dengan pusat dan sudut putar tertentu. Arah positif adalah berlawanan arah jarum jam. Bentuk dan ukuran bangun tetap.

Rotasi dengan pusat O(0, 0):
• 90° berlawanan arah jarum jam → (−y, x)
• 90° searah jarum jam → (y, −x)
• 180° (arah mana pun) → (−x, −y)
Contoh: Titik C(4, 1) dirotasi 90° berlawanan arah jarum jam dengan pusat O menjadi C′(−1, 4).

4. Dilatasi (Perbesaran / Perkecilan)

Dilatasi mengubah ukuran bangun dengan faktor skala k dari suatu pusat dilatasi. Jika k > 1 bangun diperbesar, jika 0 < k < 1 bangun diperkecil, dan jika k negatif bangun diperbesar sekaligus dibalik arahnya. Bentuk bangun tetap (sebangun), ukurannya berubah.

Pusat O(0, 0), faktor skala k: P(x, y) → P′(kx, ky)
Pusat P(a, b), faktor skala k: P(x, y) → (a + k(x − a), b + k(y − b))
Contoh: Titik D(2, −3) didilatasi [O, 3] menjadi D′(6, −9).

Contoh Soal & Pembahasan

Contoh 1

Titik A(3, −2) dicerminkan terhadap sumbu y. Tentukan koordinat bayangannya!

Penyelesaian:

Rumus refleksi terhadap sumbu y: (x, y) → (−x, y).

A(3, −2) → A′(−3, −2).

Jadi, bayangannya adalah A′(−3, −2).

Contoh 2

Titik B(4, 1) ditranslasikan oleh T(2, −3). Tentukan koordinat bayangannya!

Penyelesaian:

Rumus translasi: (x, y) → (x + a, y + b).

B(4, 1) → B′(4 + 2, 1 + (−3)) = B′(6, −2).

Jadi, bayangannya adalah B′(6, −2).

Contoh 3

Titik C(2, 5) dirotasi 90° berlawanan arah jarum jam dengan pusat O(0, 0). Tentukan koordinat bayangannya!

Penyelesaian:

Rumus rotasi 90° berlawanan arah jarum jam: (x, y) → (−y, x).

C(2, 5) → C′(−5, 2).

Jadi, bayangannya adalah C′(−5, 2).

Latihan Soal

  1. Titik P(−4, 3) dicerminkan terhadap sumbu x. Tentukan koordinat bayangannya!
    Lihat Pembahasan

    Rumus refleksi terhadap sumbu x: (x, y) → (x, −y).

    P(−4, 3) → P′(−4, −3).

    Jawaban: P′(−4, −3).

  2. Titik Q(1, −5) ditranslasikan oleh T(−2, 4). Tentukan koordinat bayangannya!
    Lihat Pembahasan

    Rumus translasi: (x, y) → (x + a, y + b).

    Q(1, −5) → Q′(1 + (−2), −5 + 4) = Q′(−1, −1).

    Jawaban: Q′(−1, −1).

  3. Titik R(6, −1) dirotasi 180° dengan pusat O(0, 0). Tentukan koordinat bayangannya!
    Lihat Pembahasan

    Rumus rotasi 180°: (x, y) → (−x, −y).

    R(6, −1) → R′(−6, 1).

    Jawaban: R′(−6, 1).

  4. Titik S(3, 4) didilatasi dengan pusat O(0, 0) dan faktor skala 2. Tentukan koordinat bayangannya!
    Lihat Pembahasan

    Rumus dilatasi [O, k]: (x, y) → (kx, ky).

    S(3, 4) → S′(2 × 3, 2 × 4) = S′(6, 8).

    Jawaban: S′(6, 8).

  5. Titik T(5, 2) dicerminkan terhadap garis y = x. Tentukan koordinat bayangannya!
    Lihat Pembahasan

    Rumus refleksi terhadap garis y = x: (x, y) → (y, x).

    T(5, 2) → T′(2, 5).

    Jawaban: T′(2, 5).
