Bab 4

Relasi dan Fungsi

Membedakan relasi dan fungsi, menyajikan dengan diagram panah atau koordinat, serta menghitung nilai fungsi.

Ringkasan Materi

1. Relasi dan Fungsi

Relasi adalah hubungan antara anggota suatu himpunan (himpunan asal) dengan anggota himpunan lain (himpunan kawan). Fungsi adalah relasi khusus dengan syarat: setiap anggota himpunan asal (domain) memiliki tepat satu pasangan di himpunan kawan (kodomain). Semua fungsi adalah relasi, tetapi tidak semua relasi adalah fungsi.

Syarat fungsi: setiap anggota domain tepat satu pasangan di kodomain

Contoh: Relasi "ibu dari" antara anak dan ibu adalah fungsi karena setiap anak punya tepat satu ibu.

2. Penyajian Fungsi

Suatu fungsi dapat disajikan dengan tiga cara: (1) diagram panah — dua lingkaran (domain dan kodomain) dengan panah penghubung; (2) himpunan pasangan berurutan, misalnya {(1, 4), (2, 6), (3, 8)}; (3) diagram Kartesius — titik-titik (x, y) pada bidang koordinat.

Diagram panah | Himpunan pasangan berurutan | Diagram Kartesius

Contoh: Fungsi yang memetakan 1 → 4, 2 → 6, 3 → 8 ditulis {(1, 4), (2, 6), (3, 8)}.

3. Domain, Kodomain, dan Range

Domain adalah himpunan asal (semua nilai x yang dimasukkan). Kodomain adalah himpunan kawan tempat hasil pemetaan berada. Range adalah himpunan hasil pemetaan yang sebenarnya, yaitu bagian dari kodomain.

Domain: himpunan asal | Kodomain: himpunan kawan | Range: hasil pemetaan sebenarnya

Contoh: Untuk {(1, 4), (2, 6), (3, 8)}: domain = {1, 2, 3}, range = {4, 6, 8}.

4. Menghitung Nilai Fungsi

Fungsi biasanya dinyatakan sebagai f(x) = … yang dibaca "fungsi f dari x". Untuk menghitung f(a), gantikan setiap x dengan a lalu hitung.

f(x) = 2x + 3, maka f(4) = 2(4) + 3 = 8 + 3 = 11

Contoh: Jika f(x) = 5x − 2, maka f(3) = 5(3) − 2 = 13.

5. Menentukan Rumus Fungsi dari Tabel

Jika diberikan tabel pasangan x dan f(x), carilah pola hubungannya. Uji rumus tebakanmu dengan semua pasangan pada tabel.

Tabel: x = 1, 2, 3 → f(x) = 4, 6, 8 ⇒ f(x) = 2x + 2

Contoh: Uji: f(1) = 2(1) + 2 = 4; f(2) = 2(2) + 2 = 6; f(3) = 2(3) + 2 = 8. Semua cocok, jadi rumusnya f(x) = 2x + 2.

Contoh Soal & Pembahasan

Contoh 1. Apakah himpunan pasangan berurutan {(1, a), (2, a), (3, b)} merupakan fungsi? Jelaskan!

Pembahasan:

  1. Periksa domain: anggota domainnya adalah 1, 2, dan 3.
  2. Masing-masing (1, 2, 3) hanya muncul sekali sebagai komponen pertama, artinya setiap anggota domain punya tepat satu pasangan. Syarat fungsi terpenuhi.

Jadi, {(1, a), (2, a), (3, b)} adalah fungsi (walaupun 1 dan 2 berpasangan dengan anggota yang sama, yaitu a).

Contoh 2. Diketahui f(x) = 3x − 5. Tentukan nilai f(7)!

Pembahasan:

  1. Gantikan setiap x dengan 7: f(7) = 3(7) − 5.
  2. Hitung: 3 × 7 = 21, lalu 21 − 5 = 16.

Jadi, f(7) = 16.

Contoh 3. Diketahui f(x) = 5x + 2. Tentukan nilai x jika f(x) = 27!

Pembahasan:

  1. Bentuk persamaan: 5x + 2 = 27.
  2. Kurangkan kedua ruas dengan 2: 5x = 25, lalu bagi dengan 5: x = 5.

Jadi, x = 5.

Latihan Soal

1. Diketahui f(x) = 4x − 1. Tentukan nilai f(6)!

Lihat Pembahasan

Kunci: 23

f(6) = 4(6) − 1 = 24 − 1 = 23.

2. Apakah himpunan pasangan berurutan {(1, p), (1, q), (2, r)} merupakan fungsi? Jelaskan!

Lihat Pembahasan

Kunci: Bukan fungsi

Bukan fungsi karena anggota domain 1 memiliki dua pasangan (p dan q), sehingga syarat "tepat satu pasangan" tidak terpenuhi.

3. Suatu fungsi linear f(x) = ax + b memenuhi f(2) = 7 dan f(5) = 13. Tentukan rumus fungsinya!

Lihat Pembahasan

Kunci: f(x) = 2x + 3

2a + b = 7 dan 5a + b = 13. Kurangkan: 3a = 6, jadi a = 2. Substitusi: 2(2) + b = 7, jadi b = 3. Rumusnya f(x) = 2x + 3.

4. Tentukan range fungsi f(x) = x² dengan domain {1, 2, 3}!

Lihat Pembahasan

Kunci: {1, 4, 9}

f(1) = 1² = 1; f(2) = 2² = 4; f(3) = 3² = 9. Jadi range-nya {1, 4, 9}.

5. Diketahui g(x) = 2x − 7. Tentukan nilai x jika g(x) = 9!

Lihat Pembahasan

Kunci: 8

2x − 7 = 9, jadi 2x = 16 dan x = 8.
